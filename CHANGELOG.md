## [1.0.0] - 2026-11-09
### Added
- `dev-workflow` plugin: commit-craft, pr-description, code-review, systematic-debugging, tdd-workflow, safe-refactor.
- `security` plugin: security-audit (with pattern scanner), secret-scanner (with history scanning), dependency-audit.
- `docs` plugin: readme-architect, changelog-keeper (with changelog generator), adr-writer, api-docs.
- `devops` plugin: dockerize, github-actions, incident-postmortem.
- `frontend` plugin: accessibility-audit, web-performance.
- Cross-agent installer, repository validator, unit tests and CI.
