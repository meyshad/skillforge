# Security Policy

## Reporting a vulnerability
Please **do not** open a public issue for security problems in the bundled scripts or installer.
Use GitHub's [private vulnerability reporting](https://github.com/meyshad/skillforge/security/advisories/new) instead.
You can expect an acknowledgement within 72 hours and a fix or mitigation plan within 14 days.

## Scope
- `scripts/install.sh` and every script under `plugins/*/skills/*/scripts/`
- Skill guidance that would lead an agent to perform an unsafe action

## Supported versions
Only the latest release on `main` receives fixes.
